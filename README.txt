Version 18.2 — อัปโหลดทั้ง 5 ไฟล์เว็บ (index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png) ไปยังโฟลเดอร์เดียวกันบน HTTPS GitHub Pages สำหรับ PWA
ประวัติเฉพาะหน้าคำนวณหลักและรายการโปรดเก็บใน localStorage จำกัด 50 รายการ ไม่เข้ารหัส
Login เดิมเป็น client-side gate ไม่ใช่ระบบป้องกันข้อมูลจริง การจำกัดการลองรหัส 5 ครั้ง/30 วินาทีเป็นเพียง UX และหลีกเลี่ยงได้ด้วยการรีโหลด
หากต้องการยืนยันตัวตนจริง: ใช้ hosting ที่รองรับการป้องกันทุก request ด้วยระบบยืนยันตัวตน เช่น Cloudflare Access บน origin ที่ปิดการเข้าถึงโดยตรง ไม่ใช่เพียงครอบหน้า GitHub Pages สาธารณะ ต้องตั้งค่าบัญชีและสิทธิ์จริงก่อนเปิดใช้งาน ไม่ได้รวม backend หรือบริการดังกล่าวในไฟล์นี้
PWA ต้องใช้ HTTPS เบราว์เซอร์ที่รองรับ; ข้อมูลสถิติออนไลน์ต้องใช้อินเทอร์เน็ต
